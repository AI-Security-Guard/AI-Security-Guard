## 📌 Overview

**AI 방법대(AI Security Guard)** 는  
CCTV 영상을 분석하여 폭력, 쓰러짐, 화재 등 이상 상황을 탐지하고 기록하는 AI 기반 영상 분석 서비스입니다.

- 🎥 CCTV 영상 분석
- 🤖 AI 기반 이상 행동 탐지
- 📋 이벤트 기록 및 관리
- 📊 분석 결과 시각화

👉 **대량의 CCTV 영상을 사람이 직접 확인해야 하는 부담을 줄이고, 위험 상황을 효율적으로 식별할 수 있는 시스템**을 만드는 데 초점을 맞췄습니다.

## ✨ Features

### 🎥 Video Analysis

* CCTV 영상 업로드 및 분석
* AI 모델 기반 위험 상황 탐지
* 분석 진행 상태 조회

---

### 🤖 AI Detection

* 폭력 행동 탐지
* 쓰러짐(Fall Down) 탐지
* 화재(Fire) 탐지
* 위험 상황별 이벤트 분류

---

### 📋 Event Management

* 탐지 결과 기록 저장
* 이벤트 발생 시각 확인
* 위험 상황별 분석 결과 조회

---

### 👤 User Management

* 회원가입 및 로그인
* JWT 기반 인증
* 사용자별 분석 이력 관리

---

### 🧠 UX Features

* 분석 작업 상태 실시간 확인
* 결과 페이지 기반 영상 검토
* 반응형 UI
